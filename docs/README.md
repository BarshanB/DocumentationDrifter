# Docs

Specs and documentation for DocumentationDrifter, in three folders:

| Folder | What it holds |
|---|---|
| [endProduct/](endProduct/README.md) | The end product: the Phase 2 specification as text, its seven diagrams and schema v14. Inspiration, not a blueprint. |
| [plan/](plan/roadmap.md) | What we actually build: the [roadmap](plan/roadmap.md), the version specs (for v1.1, [spec-v1.1.md](plan/spec-v1.1.md)), the [decision log](plan/decisions-2026-10-17.md) and the guides behind them. Where these disagree with the end product, they win. |
| [Models/](Models/v1/README.md) | The models of each version as we build it (v1 so far), narrowed from the end product's M1 to M5. |

The glossary is [CONTEXT.md](../CONTEXT.md) at the repo root, and the tickets being worked on live in `.scratch/`.
